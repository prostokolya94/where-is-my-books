# Где мои книги?

Монолитное приложение для списочного учёта личной библиотеки.

## Возможности

- **Каталог книг** — название, автор, год покупки, статус, категория, жанр, стоимость покупки.
- **Табы** — сохранённые пресеты фильтров, которые отбирают книги из общего списка по категориям, жанрам, статусам и поиску. Ядро приложения.
- **Категории и жанры** — жанр является подразделом категории. Удаление жанра или категории не удаляет книги (книга просто остаётся без жанра/категории).
- **Статистика** — матрица «жанры (строки) × категории (столбцы)» с итогами, фильтрация по статусу.

## Стек

- Бэкенд: NestJS, TypeORM, SQLite (better-sqlite3), порт `3001`, префикс `/api`.
- Фронтенд: Vite + React + TypeScript + MobX, порт `5173`, прокси на `/api`.

## Запуск

```bash
npm run setup   # установить зависимости (root, backend, frontend)
npm run dev     # поднять бэкенд (:3001) и фронтенд (:5173) одновременно
```

Откройте http://localhost:5173

База данных создаётся автоматически в `backend/data/books.sqlite` при первом запуске (schema sync).

## Команды

| Команда | Описание |
| --- | --- |
| `npm run setup` | установить зависимости |
| `npm run dev` | dev-режим: Nest watch + Vite |
| `npm run build` | продакшен-сборка backend и frontend |
| `npm --prefix backend run build` | только backend |

## Структура

```
backend/   NestJS: categories, genres, books, tabs, stats
frontend/  React + MobX: pages, stores, api-клиент
```
